Generalised Phishing Detection Architecture

  1. Host & Domain Analysis (30 Features): Pure host-level lexical, entropy, typosquatting, homoglyph, and brand impersonation patterns. Schema and paths are strictly isolated so the model never penalises legitimate deep links.
  2. Tiered HTML Content Inspection:
    • Tier 1 (Static Fetch): SSRF-guarded HTTP retrieval with TLS verification.
    • Tier 2 (Headless Chromium Fallback): When a JavaScript shell is detected, Playwright renders dynamic DOM in an isolated context with subresource route filtering.
    • Content Features (22 Features): Structured forms, inputs, passwords, stylesheets, scripts, and anchors. Toxic dataset shortcuts (LineOfCode) have been eliminated.
    • Unavailable Handling: Bot-protection challenges (Cloudflare, SiteGround) or HTTP errors are explicitly marked as unavailable rather than penalised as phishing.
  3. OSINT & Network Intelligence: Real-time RDAP domain registration age, DNS resolution, verified TLS certificate status, and threat intelligence lookups (OpenPhish, PhishTank, URLhaus, Google Safe Browsing, VirusTotal).
  4. Probabilistic Evidence Fusion: Combines calibrated ML probability with Bayesian log-odds likelihood updates for domain age, TLS, and URI indicators.
  5. Verdicts: PHISHING (≥ 70%), SUSPICIOUS (40% – 69%), LEGITIMATE (< 40%).
