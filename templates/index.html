Pipeline

  1. Host / domain features (31) - length, subdomain depth, hyphens/digits, randomness (entropy), IP host, punycode, abused TLD, free-hosting platform, shorteners, and brand impersonation (look-alike spelling, digit/letter swaps, brand inside a subdomain or combined with extra words).
  2. Page-content features (24) - title, favicon, password / hidden / external-submit forms, iframes, script & stylesheet counts, internal vs external links, copyright notice, bank/pay/crypto terms, redirects.
  3. OSINT enrichment - domain age via RDAP/WHOIS, DNS resolution, TLS certificate (validity, age, issuer), and lookups in OpenPhish, PhishTank, URLhaus, Google Safe Browsing and VirusTotal (the last three need free API keys).
  4. Rule signals - path/query indicators (@ trick, embedded URLs, executable downloads, brand in path), HTTP password forms, brand-domain allow-list. These are rules, not learned, because the training data cannot teach them reliably (see the Performance tab).
  5. Decision - final score = model probability + rule adjustments; any threat-intel hit forces PHISHING. Thresholds: ≥0.70 phishing, ≥0.40 suspicious.
